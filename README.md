# VOLTA AI Chatbot

## Overview

A production-grade AI-powered messaging chatbot and voice agent backend for the VOLTA ride-booking platform.

---

## Repository Structure

- `backend/`: Core FastAPI backend application, services, and modular AI pipeline.
- `testing-ui/`: Lightweight frontend interface for interactive testing of the chatbot.
- `docs/`: System documentation, architecture manuals, and API specifications.
- `infrastructure/`: Infrastructure configurations, deployment scripts, and container manifests.

---

## Technology Stack

- Python
- FastAPI
- PostgreSQL
- Redis
- SQLAlchemy
- LangGraph
- JWT
- Docker
- React (Testing UI)
