# VOLTA AI Chatbot - Database Documentation Hub

## Purpose
This directory contains architectural designs, database constitutions, design principles, and request flow diagrams governing data persistence for the VOLTA AI Chatbot platform.

## Contents
- `database-design-principles.md`: Official database constitution, UUID policies, timestamp policies, indexing, and soft delete rules.
- `database-architecture.md`: Request flow ASCII diagrams and layer-by-layer database architecture documentation.
